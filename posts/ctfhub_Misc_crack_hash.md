思路：给一段哈希串，要在里面还原出原文。先识别算法类型，再决定用字典、规则还是在线查询。

问题：
1. 一串十六进制，不知道是什么算法。
2. 不知道从哪开始解。
3. 解不出来，怀疑类型判断错了。

解决：
1. 用 hashid 或 hash-identifier 判断类型（长度、字符集是主要依据）。
2. MD5（32 位）先试在线反查。
3. 查不到就用 hashcat -m 0 -a 0 hash.txt rockyou.txt 跑字典。
4. 解出原文，提交通过。

补充：
1. 长度经验：32 位十六进制 = MD5，40 = SHA1，64 = SHA256，$2y$ 开头是 bcrypt。
2. 加盐哈希（如 bcrypt）只能字典，不能反查。
3. 在线反查站点适合常见明文，冷门密码还得靠本地字典 + 规则。

工具：hashid、hashcat、john、在线反查站

踩坑记录：
1. 一开始拿 32 位串当 SHA1 处理，白跑一轮。
2. hashcat 的模式 -m 选错，跑完没结果。
3. 以为是加盐的，其实是双 MD5，得先解一层再解一层。

总结：哈希题的顺序是"识别类型 → 在线查 → 字典跑 → 规则扩展"。类型判断错，后面全白干。
