思路：字符型注入，SQL 是 WHERE username='xxx' 这种形式。要先用单引号闭合，再构造条件。

问题：
1. 直接 and 1=1 报错，因为没闭合。
2. 不确定闭合后要不要注释掉后面的引号。
3. 试了几种闭合方式都不对。

解决：
1. 先输入一个单引号，看是否报错，确认是字符型。
2. 用 ' and '1'='1 闭合，对比 ' and '1'='2 的结果。
3. 或者用 # 注释掉后面的引号：' or 1=1 #。
4. 确认后 union 取数据，拿到账号密码，提交通过。

补充：
1. 注释符在 MySQL 里是 # 或 -- （-- 后面要跟空格）。
2. 闭合方式取决于原 SQL 的结构：'、''、) 加 ' 等等。
3. 字符型比数字型多一步"闭合"，其余相同。

工具：浏览器、Burp Suite

踩坑记录：
1. 忘了注释后面的引号，导致语法错误。
2. 用 -- 注释时没加空格，MySQL 不认。
3. 闭合成功但没验证 and 1=2，直接上 union，结果不对还以为是 payload 问题。

总结：字符型注入的关键是"先闭合再构造"。找闭合方式有个笨办法但很有效：一个引号一个引号地试，看哪种能报错或改变回显。
