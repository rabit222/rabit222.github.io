思路：这题把 / 拉黑了，路径里的目录分隔符不能直接写。但读一个目录里的文件，不进目录也能做到——用 cd 先切过去，再直接写文件名。

问题：
1. 写 cat /flag 直接被拦，因为里面有斜杠。
2. 不知道不写斜杠怎么指定文件。
3. 试了转义 %2f，没用，解码后还是斜杠。

解决：
1. 先确认斜杠是被过滤的对象：用不带斜杠的 ls 能执行，带斜杠的就不行。
2. 用 cd 进目录再读：cd flag_is_here;cat flag.txt。cd 参数是目录名，可以不带斜杠。
3. 也可以先 cd / 再一层层进去，每次只写一段名字。
4. 读到目标内容，提交通过。

补充：
1. 多个命令用分号连起来，cd 的效果会延续到下一条命令，这是关键。
2. 真正的目录分隔符在 Linux 上是 /，在 Windows 上是 \，环境不同写法不同。
3. 服务端若用 escapeshellarg 之类严格处理，这类技巧都会失效——黑名单不可靠，正确的做法是不把输入拼进命令。

工具：Burp Suite

踩坑记录：
1. 一开始想用编码绕斜杠，结果 PHP 解码之后还是斜杠，白折腾。
2. 忘了 cd 之后当前目录会保留，第一次写了 cd dir 却没接着读文件。
3. 目录名记错，进去之后 ls 才发现还有一层。

总结：过滤斜杠的绕过思路是"避免写路径"——先切换目录，再操作。这题也说明：命令注入的过滤器只要漏掉一个连接符就形同虚设。
