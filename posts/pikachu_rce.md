思路：Pikachu 的 RCE 模块分两种：eval 型（代码执行，直接把输入当 PHP 执行）和 ping 型（命令执行，把输入拼进系统命令）。

问题：
1. 分不清"代码执行"和"命令执行"的区别。
2. eval 型不知道该怎么写 payload。
3. ping 型试了分号没反应。

解决：
1. eval 型：输入 phpinfo(); 或 system('whoami');，观察页面输出，确认代码被执行。
2. 接着用 system('cat /flag') 之类读文件，或者直接 file_get_contents。
3. ping 型：输入 127.0.0.1;ls，用分号接命令，确认回显。
4. 换成读文件的命令，拿到内容，提交通过。

补充：
1. 代码执行（eval/assert）的输入是 PHP 语句，不加分号会报错；命令执行（system/exec）的输入是 shell 命令。
2. 命令执行要理解 shell 连接符：; | || && & 换行。
3. 防御：绝对不要对用户输入用 eval；命令执行用参数数组 + 白名单。

工具：浏览器、Burp Suite

踩坑记录：
1. eval 型的 payload 忘了写分号，一直语法错误。
2. ping 型用 && 但前面的命令失败，导致后面不执行。
3. 一开始以为两种是同一回事，理解之后才发现利用方式完全不同。

总结：代码执行和命令执行只有一字之差，但需要的东西完全不同：一个要求懂 PHP，一个要求懂 shell。这题把两者放在一起，对比着理解最有效。
