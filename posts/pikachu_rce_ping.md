思路：页面有个 ping 功能，输入会拼进 shell 命令。用分号、管道、&& 这类连接符追加命令，输出会回显在页面上。

问题：
1. 不确定输入有没有进 shell。
2. 分号试了没反应。
3. 命令有空格，URL 里被截断。

解决：
1. 先试 127.0.0.1;ls，看是否列出目录。
2. 用分号或 && 接命令，读目标文件。
3. 空格用 %20 编码，或者用 IFS 变量绕过。
4. 拿到内容，提交通过。

补充：
1. shell 连接符：分号顺序执行、&& 成功才执行、|| 失败才执行、| 管道。
2. 有回显时直接读；无回显就用外带（curl 到自己的服务器）或时间盲打。
3. 防御：不拼接命令，用参数数组 + 白名单。

工具：Burp Suite

踩坑记录：
1. 用了 && 但前面的 ping 失败，后面不执行。
2. 命令里的管道符在表单里没编码。
3. 目录不对，flag 路径猜错几次。

总结：命令注入的核心是"理解 shell 语法"。连接符、管道、重定向，这些都是绕过和利用的基础。
