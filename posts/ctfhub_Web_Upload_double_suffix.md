excerpt: 过滤规则是把 php 替换成空，写两遍就还原成 php。
---

思路：这题的黑名单是把文件名里的 php 字符串删掉（不是拒绝）。删一次的话，写 pphphp 删掉中间的 php 之后正好剩 php。

问题：
1. 传 shell.php 变成 shell.，后缀被吃掉了。
2. 不知道过滤是"拒绝"还是"删除"，两种情况的应对完全不同。
3. 试了大写和加点绕法都不行。

解决：
1. 传 shell.php，观察保存的名字变成了 shell.，说明是替换为空字符串。
2. 构造 shell.pphphp：过滤删除一次 php 之后，剩下 shell.php。
3. 上传成功，访问执行，提交通过。

补充：
1. "删除型"过滤比"拒绝型"更好绕，因为它只做一次替换，嵌套一次就还原了。
2. 变体：.php5/.phtml/.phar 等其他可执行后缀，或者大小写混写（看过滤是否区分大小写）。
3. 防御：不要用字符串替换做校验，用白名单 + 重命名 + 上传目录禁执行。

工具：Burp Suite

踩坑记录：
1. 没先确认过滤类型，直接按"拒绝"的思路去绕，浪费了几轮。
2. 双写的位置写错，其实关键是"删完要正好剩下想要的后缀"。
3. 上传后文件名被改成随机串，差点以为失败，其实是成功了，只是路径不同。

总结：这道题的关键是"搞清楚过滤做了什么"——拒绝、删除、编码三种处理方式的绕过手法完全不同。先观察被处理后的结果，比猜规则快得多。
