title: Pikachu-越权(水平)
date: 2026-11-23
tags: [Pikachu, WEB, 越权]
excerpt: 改个 id 就能看别人的资料，同一权限级别的越权。
---

思路：普通用户之间的越权。页面用 id 参数区分用户，改成别人的 id 就能看到对方信息。

问题：
1. 不知道有没有越权。
2. 参数在哪、怎么改。
3. 改了 id 看不到东西。

解决：
1. 先用两个账号（A、B）登录，分别记录能看到的数据。
2. 用 A 登录，把请求里的 id/user 参数改成 B 的。
3. 如果能看到 B 的数据，水平越权成立。
4. 逐条翻，找到目标信息，提交通过。

补充：
1. 水平越权 = 同级别用户互相越权，垂直越权 = 低权限访问高权限功能。
2. 常见参数：id、uid、user_id、userid、username。
3. 防御：服务端从会话里取当前用户，不信任前端传来的身份参数。

工具：Burp Suite

踩坑记录：
1. 一开始没造两个账号，不好对比。
2. 参数名猜错，改了没效果。
3. 有的接口用 cookie 判断身份，改参数无效。

总结：越权是"逻辑漏洞"，扫描器扫不出来，只能靠人理解业务。判断标准很简单：服务端有没有校验"你能看这条数据吗"。
