date: 2026-11-23

excerpt: 输入落在 LIKE '%xxx%' 里，要用 % 和引号一起闭合。
---

思路：搜索框的 SQL 是 WHERE xxx LIKE '%输入%' 这种形式，闭合需要处理两边的 % 和引号。

问题：
1. 直接输入引号，报错位置和普通字符型不一样。
2. 不知道怎么处理 LIKE 里的 %。
3. 输入 % 直接被当成通配符，分不清是数据还是语法。

解决：
1. 先输入单引号看报错，确认落在 LIKE 的字符串里。
2. 用 %' and '1'='1 闭合：前面的 % 补全 LIKE，后面的 ' 闭合字符串。
3. 确认注入成立后，order by 数列，union 取数据。
4. 拿到账号密码，提交通过。

补充：
1. 搜索型本质是字符型，只是多了 LIKE 的通配符上下文。
2. 也可以直接用 %' union select ... # 一步到位。
3. 防御：参数化查询，任何上下文都一样。

工具：浏览器、Burp Suite

踩坑记录：
1. 一开始只用 ' 闭合，报错但没分析清楚。
2. 把 % 当普通字符，没意识到它在 SQL 里是通配符。
3. union 时列数没数，报错后才发现前面还有 id 列。

总结：搜索型注入说明"同一个漏洞在不同的 SQL 上下文里需要不同的闭合"。上下文不同，payload 就得改，但底层原理不变。
