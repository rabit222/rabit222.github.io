思路：分号、|、& 这些连接符都被过滤了。但 shell 里执行第二条命令的方式还有很多：换行、命令替换、后台符号。

问题：
1. ; 和 | 都被拦，常规连接方式失效。
2. 不确定还有哪些方式能接命令。
3. 试了 && 也不行，说明过滤面挺大。

解决：
1. 用换行：%0a 在 URL 里代表换行，shell 会把换行当作命令分隔。
2. 用命令替换：反引号或者 \$(id)，把结果嵌进参数里。
3. 用 %26（&）或 %7c（|）的变体配合其他连接符。
4. 拿到执行结果，提交通过。

补充：
1. shell 里能"接第二条命令"的方式：; | || && & 换行 命令替换 后台任务。
2. 黑名单过滤连接符的思路永远堵不全，因为语法糖太多。
3. 真实防御：不拼接、不调用 shell，直接 exec 参数数组。

工具：Burp Suite

踩坑记录：
1. 一开始只盯着分号和管道，没想到换行也行。
2. 换行在 Burp 里要 URL 编码，直接回车会把请求头截断。
3. 用了反引号但嵌套在引号里被提前处理，位置得注意。

总结：绕过连接符过滤的关键是"知道 shell 有几种命令分隔方式"。这类题的核心不是背 payload，而是理解 shell 语法本身。
